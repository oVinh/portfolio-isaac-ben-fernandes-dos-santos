# 🎬 Site Multi Páginas - Bootstrap

## 📝 Descrição do Projeto

Este projeto consiste no desenvolvimento de um site sobre **jogos clássicos e a história dos videogames**. O objetivo é apresentar a evolução dos consoles e alguns jogos que marcaram diferentes gerações, utilizando páginas organizadas e uma navegação simples.

Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**, o site possui cinco páginas: Início, Sobre, Galeria, Dados e Contato. Foram utilizados HTML5, CSS3 e Bootstrap 5 para organizar os conteúdos e criar elementos visuais como menu responsivo, carrossel de imagens, cartões, janelas de informações e perguntas interativas.

## 🚀 Tecnologias Utilizadas

* **Linguagens:** HTML5 e CSS3
* **Bibliotecas:** Bootstrap 5.3.3 (incluindo seus componentes JavaScript)
* **Ferramentas:** VSCode
* **Modelo de IA:** Gemini

## 📊 Resultados e Aprendizados

O projeto resultou em um site com cinco páginas interligadas, apresentando conteúdos sobre a história dos videogames e jogos conhecidos.

* **Estrutura de páginas:** Aprendi a criar páginas HTML e a conectá-las por meio de um menu de navegação.
* **Bootstrap:** Pratiquei o uso de classes de layout responsivo, botões, cartões, carrossel, modais e Accordion.
* **Organização de conteúdo:** Trabalhei com imagens, textos, uma tabela de consoles e um formulário de contato. O formulário possui campos visuais, mas não está conectado a um serviço de envio de mensagens.

## 🧠 Declaração de Uso Ético da IA

Durante o desenvolvimento deste projeto, utilizei a inteligência artificial **Gemini** como ferramenta de apoio ao aprendizado e à programação.
A IA me auxiliou principalmente na compreensão das funcionalidades do **Bootstrap 5**, explicando como utilizar seus componentes, onde encontrá-los na documentação e como aplicá-los corretamente nas páginas do site.
Também utilizei a ferramenta para esclarecer dúvidas sobre HTML e CSS, identificar possíveis erros nos códigos, receber sugestões de correção e compreender melhor o funcionamento de alguns elementos.
O uso da inteligência artificial teve como objetivo facilitar o aprendizado e apoiar o desenvolvimento do projeto, permitindo que eu compreendesse melhor as tecnologias utilizadas e aprimorasse meus conhecimentos em desenvolvimento Front-End.
