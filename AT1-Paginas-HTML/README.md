# 🎬 Páginas HTML

## 📝 Descrição do Projeto

Este projeto consiste no desenvolvimento de um site para uma cafeteria fictícia chamada **Café no Bairro**. O objetivo principal é apresentar o estabelecimento, seu cardápio, suas imagens e informações de contato, utilizando uma estrutura simples e organizada.

Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**, o site possui cinco páginas HTML interligadas: Início, Sobre Nós, Cardápio, Galeria e Contato. A aplicação utiliza HTML5 para organizar os conteúdos e CSS3 para personalizar cores, fontes, espaçamentos e elementos visuais.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** HTML5 e CSS3
* **Bibliotecas:** Nenhuma biblioteca externa
* **Ferramentas:** VSCode
* **Modelo de IA:** Gemini

## 📊 Resultados e Aprendizados

O projeto resultou em um site com cinco páginas interligadas, apresentando uma identidade visual própria para a cafeteria.

* **Estrutura HTML:** Aprendi a organizar páginas utilizando títulos, parágrafos, imagens, listas, links e elementos semânticos.
* **Estilização CSS:** Pratiquei a personalização de cores, fontes, espaçamentos e a utilização de Flexbox para organizar o menu de navegação.
* **Organização do Projeto:** Aprendi a separar os arquivos HTML, CSS e imagens em pastas, facilitando a manutenção do site.

## 🧠 Declaração de Uso Ético da IA

Este projeto registra o uso da ferramenta de inteligência artificial Gemini como apoio tecnológico para apoio e correção dos códigos. A utilização da IA deve representar as atividades efetivamente realizadas durante o desenvolvimento do projeto.
