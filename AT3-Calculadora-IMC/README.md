# 🧮 Calculadora de IMC

## 📝 Descrição do Projeto

Este projeto consiste no desenvolvimento de uma **Calculadora de Índice de Massa Corporal (IMC)**, com o objetivo de permitir que o usuário informe seu peso e altura e receba automaticamente o resultado do cálculo, acompanhado de sua classificação.

Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**, o projeto utiliza HTML5, JavaScript e Bootstrap 5 para criar uma interface simples, organizada e interativa.

A calculadora realiza o cálculo do IMC a partir dos valores informados, identifica a classificação correspondente e apresenta o resultado com alertas visuais de diferentes cores. Também possui validação dos campos de entrada e uma tabela de referência com as classificações de IMC para adultos.

## 🚀 Tecnologias Utilizadas

* **Linguagens:** HTML5, CSS3 e JavaScript
* **Bibliotecas:** Bootstrap 5.3.3
* **Ferramentas:** VSCode
* **Modelo de IA:** Gemini

## 📊 Resultados e Aprendizados

O projeto resultou em uma calculadora funcional, capaz de receber os dados do usuário, realizar o cálculo do IMC e apresentar sua classificação de forma clara e organizada.

* **Lógica de Programação:** Aprendi a utilizar variáveis, operadores matemáticos, funções e estruturas condicionais em JavaScript para realizar cálculos e determinar classificações.
* **Validação de Dados:** Pratiquei a verificação dos valores informados pelo usuário, identificando campos vazios, valores inválidos e números negativos ou iguais a zero.
* **Manipulação do HTML:** Aprendi a utilizar JavaScript para capturar informações dos campos e atualizar dinamicamente os resultados apresentados na página.
* **Bootstrap:** Pratiquei a utilização de componentes como cards, botões, tabelas e alertas, além de classes para estilização e organização responsiva.
* **Interatividade:** Desenvolvi uma aplicação que responde às informações fornecidas pelo usuário, apresentando o resultado do cálculo e sua classificação com diferentes cores.

## 🧠 Declaração de Uso Ético da IA

Durante o desenvolvimento deste projeto, utilizei a inteligência artificial **Gemini** como ferramenta de apoio ao aprendizado e à programação.

A IA auxiliou na compreensão de funcionalidades do HTML, JavaScript e Bootstrap, oferecendo explicações sobre a utilização de componentes, estruturas condicionais e manipulação de elementos da página.

Também foi utilizada como apoio na identificação e correção de possíveis erros nos códigos, esclarecimento de dúvidas e compreensão da lógica utilizada no cálculo e na classificação do IMC.

O uso da inteligência artificial teve como objetivo complementar o aprendizado, facilitar a compreensão das tecnologias utilizadas e auxiliar no desenvolvimento da aplicação.
